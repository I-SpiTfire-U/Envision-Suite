# Envision Suite

A Linux GUI suite for configuring and managing SCUF Envision Pro V2 and Envision Pro V2 Wired controllers.

Based on [Scufpad](https://github.com/ChaseDRedmon/Scufpad).

> **Warning:** Envision Suite is still heavily under development and will not be ready for general use for some time.
